面向 Codex、Claude Code 与 Antigravity 的发送前意图与预设控制层。 A pre-send intent and preset layer for Codex, Claude Code, and Antigravity.

话没说透时，先补齐工程预设、交付可逆初版并列出最多 2 个关键选择题；方向拍板后，跨轮锁死已确认的规矩，走偏时一键回退本地会话。 When a prompt is underspecified, it attaches stack presets, ships a reversible v1, and surfaces at most 2 key choices; once decided, it locks rules across turns and rolls back drifted sessions cleanly.

只解决三个最常卡壳的瞬间 Built for Three Everyday Friction Points

  • 第一轮话没说全 —— 自动挂载 UI 排版（tabular-nums、克制色板、防连点）、SQLite 写锁与科研统计规范，拒绝廉价蓝紫模板和十连追问。 Underspecified Turn 1 — Automatically attaches UI craft (tabular-nums, restrained palettes, submit locks), SQLite write locks, and statistical rigor without purple-gradient slop or 10-question stalls.
  • 聊久了忘规矩 —— 自动提取你已确认的决定（含“不要物理删除”等否定要求），后续每一轮持续生效。 Forgotten rules on Turn 10 — Captures confirmed decisions (including negations like "Never hard-delete") and carries them across every follow-up turn.
  • 走偏后越改越乱 —— lacuna rebase 自动备份并物理截断本地 .jsonl 错误轮次，带着已锁定的规矩干净重跑。 Rabbit-hole turns — lacuna rebase backs up and truncates drifted .jsonl turns so you rerun cleanly with locked rules intact.

你的本轮明确指令永远排第一，一句话即可覆盖任何默认预设。 Your explicit instructions always come first—override any default preset in a single sentence.

从方向未定到持续推进 From Open Direction to Locked Execution

方向未定时 Before You Decide

先按状态标记或预览模式交出能跑的第一版，代码结束后最多只问 2 个决定后续走向的大白话选择题。 Delivers a runnable, reversible v1 first, then asks at most 2 plain-language trade-off choices outside the code block.

方向拍板后 Once You Confirm

拍板内容写进当前会话规矩清单，你改主意时自动更新覆盖；Codex 桌面端、CLI、Claude Code 与 Antigravity 同步可用。 Confirmed choices stay locked for the rest of the session, update cleanly if you change your mind, and work across Codex App/CLI, Claude Code, and Antigravity.

常用命令 Everyday Commands 

# 查看或切换语言 (auto 默认自动识别 | zh | en)# Inspect or switch language (auto | en | zh)
lacuna config show
lacuna config set lang en

# 查看或撤销当前会话已锁定的规矩# List or revoke locked rules in current session
lacuna rules list
lacuna rules revoke --id r_1

# 备份并回退最近 1 轮走偏会话 / 一键卸载# Backup & roll back last 1 drifted turn / cleanly uninstall
lacuna rebase <session_id> 1
lacuna uninstall
