未竟之意（Lacuna） 是挂载在 Codex CLI、Claude Code 与 Antigravity 前面的模型前置引擎。 Lacuna (未竟之意) is a zero-latency pre-model hook engine for Codex CLI, Claude Code, and Antigravity.

它在提示词发往模型前毫秒级介入：自动补齐 UI、数据库与科研统计底线；需求还没拍板时，让模型先交出安全可逆的第一版并列出 2 道关键选择题；一旦你拍板，后续多轮全程锁死规矩，跑偏还能直接回退会话文件。 Before your prompt reaches the model, Lacuna injects stack-matched craft and safety baselines locally in under 15ms. When direction is still forming, it ships a reversible v1 plus 2 clear choices; once you decide, it locks your rules across turns and supports physical session rollback.

    02 / Capabilities
    
        
    
          
    
            不抢方向盘，也不让你每轮重复盯细节。
            Never hijacks your direction. Never makes you repeat your rules.
          
    
          
    
            普通 AI 工具要么一次吐出十几个追问把你卡在原地，要么一声不吭替你做不可逆的物理删除。未竟之意在模型前置层把分工重新划清楚。
            Typical AI workflows either stall you with a wall of questions or silently hardcode destructive defaults. Lacuna enforces a clean division of labor before generation starts.
          
    
        
    
      
    

      
    
        
    
          
    01 · Pre-Model Architecture
    
          
    
            纯粹模型前置，AI 无需学习新工具
            Strictly Pre-Model, Zero Tool Overhead
          
    
          
    
            通过各宿主的原生前置入口（UserPromptSubmit / PreInvocation）工作。不占 MCP 工具槽位，不靠模型“自觉想起来调用”，每次发话前稳定生效。
            Hooks directly into native UserPromptSubmit and PreInvocation events. No MCP tool clutter, no hoping the model remembers to call a helper, and zero extra network latency.
          
    
        
    

        
    
          
    02 · Open Direction
    
          
    
            先交可逆第一版，再摆 2 道大白话选择题
            Reversible V1 First + 2 Plain-Language Choices
          
    
          
    
            当数据保留策略、并发冲突或异常样本去留还没拍板时，先按状态标记或预览模式交出能跑的第一版，并在结尾只列最多 2 个决定后续走向的问题请你拍板。
            When data retention or edge-case policy is still open, the model delivers a working reversible v1 first, then surfaces at most 2 concrete binary choices in plain language for you to confirm.
          
    
        
    

        
    
          
    03 · Long-Horizon Memory
    
          
    
            跨轮否定句精准提取 + 跑偏物理截断
            Negation-Aware Decision Lock & File Rebase
          
    
          
    
            精准区分反问句与正式拍板，完整保留“不要物理删除 / Never hard-delete”等否定语义；你改主意时自动覆盖旧决定；模型若走偏，lacuna rebase 自动备份并截断回退 .jsonl 会话。
            Distinguishes questions from real decisions, preserves negations like "Never hard-delete", supersedes cleanly when you update your mind, and backs up + truncates drifted .jsonl turns via lacuna rebase.
          
    
        
    

        
    
          
    04 · Windows & Bilingual
    
          
    
            Windows 原生兼容 & 中英文彻底隔离
            First-Class Windows & Pure English Support
          
    
          
    
            完整处理 Windows 路径空格、cmd.exe 引号规则与 CRLF 换行。写中文自动注入中文底线，写英文自动注入纯正英文底线（零中文字符混入），与普通翻译/闲聊互不干扰。
            Handles Windows cmd.exe / PowerShell quoting, spaces in paths, and CRLF transcripts natively. English prompts trigger 100% pure English context; casual non-coding chats stay completely untouched.

    CLI Quick Reference
    
          
    
            常用终端管理命令
            Everyday Terminal Controls
          
    
          
    # 查看当前设置 / Inspect active settings
lacuna config show

# 切换语言 (auto 自动识别 | zh 中文 | en 纯英文)
lacuna config set lang auto

# 固定默认视觉气质 / Set default UI archetype
lacuna config set visual.default warm-editorial

# 查看或撤销当前会话已锁定的决定 / Manage session decisions
lacuna rules list
lacuna rules revoke --id r_1

# 物理截断回退走偏的最近 1 轮会话 / Roll back drifted turn
lacuna rebase <session_id> 1
