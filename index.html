作用 Features

  • 前置预设 —— 发给模型前按任务附加前端排版、数据库事务与统计检验基线；当轮显式指令始终优先，英文输入自动注入纯英文上下文。 Task Presets — Attaches frontend, database, and statistical baselines before prompts reach the model. Explicit instructions take precedence; English prompts stay 100% English.
  • 会话约束 —— 自动记录当前会话内已定的约束（如表结构、软删除策略），后续轮次持续附带，可通过 lacuna rules 查看、添加或撤销。 Session Rules — Carries confirmed session constraints (schemas, soft-delete policies, etc.) across turns. Inspect, add, or revoke via lacuna rules.
  • 记录回退 —— lacuna rebase <session_id> [turns] 自动备份并截断本机 Codex 或 Claude .jsonl 最后 N 轮对话。 JSONL Rollback — lacuna rebase <session_id> [turns] backs up and truncates the last N turns of local Codex or Claude .jsonl logs.

命令与安装 Commands & Setup 

lacuna config show                  # 查看当前配置# Show active configuration
lacuna config set lang auto         # 语言：auto（默认）| zh | en# Language: auto (default) | en | zh
lacuna rules list                   # 查看当前会话约束# List constraints in active session
lacuna rules revoke --id <id>       # 撤销指定约束# Revoke a constraint by ID
lacuna rebase <session_id> [turns]  # 备份并截断最后 N 轮 .jsonl# Back up and truncate last N .jsonl turns
lacuna uninstall                    # 卸载前置 Hook# Remove pre-model hooks
